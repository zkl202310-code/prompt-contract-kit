## 为某模型出专版时的改写起点（仍须达到预注册通过条件）
- **GPT-5.6**：不改文件，改适用条件——本组任务上 none 档为负，作者的做法是只在开推理的档位用；其他任务未验证。
- **GPT-6**：本组任务上两步式为负；一步式刚达线（规则 3 改条件式长度限制后也只 0.55）；作者的做法是先不用。
- **DeepSeek**：放宽长度与分节限制；「成功标准」里加「覆盖原问题全部子项并给补齐建议」；保留防编造条。
- **Kimi**：「可变信息」改为「留空并用〔〕标出，不得代填」，加一条禁填规则；再测编造项。
- **Claude（Fable 5.2 / Opus 5.5）、GPT-6.1 家族、Gemini 4、豆包、GLM**：截至 2026-11-15 仍无作者 A/B 数字。不要把上表 GPT-5.6 / Astra 的结果套到这些模型上；若要声明效果，先按仓库根目录 `eval/README.md` 跑一次原样 A/B。

## 方法上踩过的坑
- 同一文件两次运行不编造项 8-11-1 与 8-9-3，波动足以跨过或跌出条件线——单次运行不可靠，条件要预注册。
- 两判官逐题一致率曾只有 11/20；表中双判官各自的 20 题结果分别列出，不合并。
- 平局要单列（13-2-5 不是 15-5）；字符数用 `len()`，`wc -m` 在 C locale 下给字节数。
- 在判官 × 执行模型的 2×2 拆分里，换判官不改变方向、换执行模型才改变（同一批输出换判官时长度比不变）；公开数字只支持「方向不随判官变」，不足以做更强的归因。
- 人工校准 7 对、一致 5/7、κ 0.44——刚过 0.4。
- 术语：harness = 评测脚本与运行环境；effort / 思考档 = 模型推理强度参数；trace = 模型逐步输出记录；PTC = OpenAI 的 programmatic tool calling。
